# 运行、缓存与断点续跑

当前推荐配置是四题并行、进程内请求合计上限二、本地视频预处理单路。文本使用plus，视频使用max；实际额度与服务状态以账户为准。

## 新建实验

```bash
source scripts/env.sh
bash scripts/run_tasks.sh --dry-run --all
PYTHONUNBUFFERED=1 KDD_RUN_TIMEOUT=24h bash scripts/run_tasks.sh --all
```

`--all` 仅运行公开60题，不是完整410题。单题参数如 `task_44`，多题子集如 `task_44,task_127`。普通单题默认30分钟、子集2小时、全量8小时，可用 `KDD_RUN_TIMEOUT` 覆盖。

脚本读取 `.env`，也可用 `KDD_ENV_FILE` 指定配置。配置文件中的非空字段优先于终端；显式空令牌会阻止调用。API令牌不参与实验指纹，也不会写入源码快照或请求统计。

普通启动会创建 `runs/<编号>/` 并实时输出日志。源码、依赖、输入、ASR权重、模型与关键调度设置会记录在 `run_manifest.json`，单题完成后写入CSV哈希和成功凭据。

## 查看进度

```bash
tail -n 80 -F runs/<实验目录>/console.log
watch -n 5 'python scripts/monitor_run.py runs/<实验目录> | python -m json.tool'
```

关注 `process_running`、`runtime_state`、`active_tasks`、`successful`、`http_status_this_session` 和 `request_budget`。监控能识别进程丢失；完成后计时冻结，不会将查看时间计入实验耗时。`attempted` 是当前日志树中的计时记录数，历史复用实验应结合完成凭据与会话记录判断覆盖情况。

`successful` 表示预测文件与完成凭据有效，不代表答案正确。评分必须等运行结束后独立进行。

## 两种续跑方式

原地续跑适合中断后保留同一实验目录：

```bash
python -u scripts/resume_current_run.py runs/<实验目录>
```

它先验证源码、输入、模型、设置与成功预测的哈希，只重试未完成题目；旧尝试日志保存在本目录的 `sessions/`。重复启动会被拒绝。该入口在退出后自动评分。

也可以新建一个结果目录，严格继承匹配的成功结果：

```bash
KDD_RUN_TIMEOUT=24h bash scripts/run_tasks.sh --resume runs/<来源实验目录> --all
```

这一方式由普通启动脚本负责输出检查，结束后需要执行 `python scripts/evaluate_run.py runs/<新目录>`。来源必须有匹配的manifest与成功凭据；复制一个CSV不足以构成合法续跑。

## 配置或源码变化

默认续跑拒绝不一致的设置。仅调整任务并发时，可显式使用：

```bash
# 在本机.env中修改MAX_PARALLEL后
python scripts/resume_current_run.py runs/<实验目录> --allow-task-parallel-change
```

模型路由或代码升级需要 `--reviewed-routing-change` 指定经过审查的旧/新源码及设置哈希清单。工具会保存原manifest、完成凭据与评分，再记录变更。此类结果是带历史输出的修复实验，不是新模型的纯独立全量基线。不要直接手改manifest来强行复用。

## 文档缓存与快速模式

`KDD_DOC_CACHE_MODE=readwrite` 启用完整成功文档缓存，`off` 用于每轮独立预处理。失败分区、归一化错误和校验损坏的内容不复用。模型、思考参数、内容、知识背景和相关处理代码不同会改变指纹；未声明模型版本时按日期隔离。

缓存主要加速同一条件的重复实验，不能保证首次全量运行大幅缩时。当前不缓存任务答案，模型变更后的有效预测也不能直接当成相同实验产生。

`--fast` 会启用文档缓存并调整已知服务的请求上限。单模型plus可能覆盖为4；配置视频max时会将上限限制在不超过3，并保留更小的用户值。当前模板的请求上限2在混用快速模式下仍为2。复现实验时优先显式记录设置，不要把快速模式当成固定加速倍数。

## 时间与质量

本轮最终26题补跑用时71分29秒，但完整调试包含失败与中断，不能用它代替从零60题的耗时。比较模型或优化效果时，应固定题集、缓存、并发、代码与评分器，并单独记录冷启动、缓存复跑和历史结果复用。
